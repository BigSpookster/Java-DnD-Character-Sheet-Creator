# Java-DnD-Character-Sheet-Creator
  This was my final assignment for Object Oriented Programming, which I took with Professor Arup Guha at UCF in the Spring of 2026.
  The following is the explanation I submitted for my program.

# My Thought Process Behind This Program:
  I decided to write an application that can generate a Dungeons and Dragons character sheet based on a user’s input. The audience for this program is any individual who has a basic understanding of the rules of Dungeons and Dragons and enjoys the game. I hope my code is not too confusing for someone who does not know the rules, but I can see how it could be.
I chose this program for many reasons. The first reason is that I thought it would be fun and useful for my future since I want to be a game developer. The second reason is that I think it lines up with the goal of using a subset of the things I have learned this semester. I created and utilized my own exceptions, I created many object classes, I used inheritance, and I even got a better understanding of the purpose behind static methods in object classes. This leads into the third reason I chose this program; I knew I would have to create many different types of objects, and I knew those objects would all bounce off each other in multiple ways. This was always my worst area throughout the whole course. When a program is small, I can easily comprehend it, but when it starts to grow, my understanding crumbles. Thus, I wanted to challenge myself; if I get better with large-scale classes, the smaller ones on the final exam will feel much easier to wrap my head around. This lines up perfectly with the second goal of the assignment, which is to properly prepare myself for the final exam. As a side note, I did not realize how shaky my foundations were when it came to exceptions before I made this program. Now, I am much more confident I will knock any exception question out of the park on the final.

# How to Navigate the Program:
  The file to run is CharacterCreator.java. This has the main within it and other methods that are utilized in the main to make it more compact. As long as the two text files (classList.txt and backgroundList.txt) are in the correct directory for the command prompt or whatever IDE is being used, it should run smoothly. I tried to make the prompts descriptive enough for the program to be figured out without issue. Also, I think I caught all the things that can crash the program, so there is room for error when using it. Essentially, there is not that much instruction to give because a lot of the work I did went into making the program user-friendly.
  There is a lot of functionality that goes unused within the many other classes I wrote; if I had more time, I would have utilized these in the main. To see those, I recommend checking out my code, which is all commented. I tried to make the comments as in depth as I could. There are also some holes that people who know Dungeons and Dragons might see, like the missing skill proficiencies. Unfortunately, implementing every aspect of a character sheet was outside the scope of my allotted time, at least for now. Overall, I see this program as a proof of concept more than a tool that is extremely useful as it is. If I continue to develop it, the program will become much more powerful.
